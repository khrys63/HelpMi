# Rapport d'audit ISO 27001:2022 — Application HelpMi

**Date** : 07 mai 2026
**Périmètre** : Code source + configuration de l'application HelpMi (Java 21 / Spring Boot 3.5 / Vue 3 / Keycloak / PostgreSQL / S3/MinIO / Docker Compose)
**Auditeur** : Analyse statique du code source
**Méthodologie** : Revue exhaustive du code mappée sur les contrôles de l'Annexe A d'ISO 27001:2022

> **Note préliminaire** : L'ISO 27001 porte sur un SMSI (Système de Management de la Sécurité de l'Information) dans sa globalité. Une partie des contrôles (gouvernance, RH, physique) est **hors périmètre** d'une revue de code. Ce rapport couvre en priorité les **contrôles technologiques (A.8)** et les contrôles organisationnels **observables dans le code** (A.5).

```java
// ProjectService.java — contrôle d'accès impératif
private void requireProjectAccess(UUID projectId) {
    User u = currentUserService.getCurrentUser();
    if (u.getRole() == UserRole.ADMIN) return;
    if (!userProjectRepository.existsByUserIdAndProjectId(u.getId(), projectId))
        throw new ForbiddenException("Accès refusé");
}
```

## Points forts à retenir

Le code HelpMi montre un **niveau de maturité sécurité appréciable** pour un projet développé from scratch, notamment :

- Délégation complète de l'authentification à Keycloak (OAuth2 PKCE S256), aucun mot de passe géré en propre
- Personal Access Tokens avec entropie 256 bits, hashés SHA-256, révocables, auditables, avec rate limiting
- Toutes les requêtes SQL via JPQL paramétré — injection SQL impossible
- Détection MIME binaire par Apache Tika (pas de confiance dans l'extension)
- Tokens JWT stockés en mémoire vive Pinia (non vulnérables au vol via XSS)
- Architecture fail-secure : par défaut tout accès est refusé
- Journal d'audit structuré avec IP, acteur, horodatage

Les **principales actions restantes** sont : activation du TLS Let's Encrypt en production, fermeture du port MariaDB exposé, ajout du header Content-Security-Policy, et implémentation technique des droits RGPD (export et suppression de compte).
